# BEII Order Menu

Open `index.html` in a browser to test the website.

Admin password: `beii0722`

Important:
This standalone build stores product/catalog changes in the browser's localStorage. It is therefore ideal for testing and single-device use, but it does NOT yet provide a shared cloud database where every customer's phone sees the same live inventory/admin changes.

For a true public link with shared live inventory and admin changes across all customers, connect the same UI to a hosted backend/database (for example Supabase/Firebase) before deployment.
